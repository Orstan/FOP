# ФОП Помічник

**Повнофункціональний сайт для українських підприємців з пасивною монетизацією**

Безкоштовний конструктор документів, розумні калькулятори податків та експертний блог для ФОП.

## 🚀 Особливості

### ✅ Вже реалізовано:

1. **Конструктор документів**
   - Договір надання послуг (з попереднім переглядом)
   - Інтерактивні форми з валідацією
   - Готовий до інтеграції PDF-генерації

2. **Розумні калькулятори**
   - Калькулятор податків ФОП (групи 1, 2, 3)
   - Автоматичний розрахунок Єдиного податку та ЄСВ
   - Детальний розбір результатів

3. **SEO-блог**
   - Стаття "Податки ФОП у 2026 році"
   - Структура для додавання нових статей
   - SEO-оптимізація (metadata, keywords)

4. **Темна/світла тема**
   - Автоматичне визначення за системними налаштуваннями
   - Перемикач місяць/сонце
   - Адаптивний дизайн

## 🛠 Технології

- **Next.js 16** (App Router) - SSR/SSG для відмінного SEO
- **TypeScript** - типізація для надійності
- **Tailwind CSS v4** - сучасна стилізація
- **shadcn/ui** - красиві UI-компоненти
- **next-themes** - підтримка тем
- **Lucide React** - іконки

## 📦 Встановлення

```bash
npm install
```

## 🚀 Запуск

```bash
npm run dev
```

Відкрийте [http://localhost:3000](http://localhost:3000) в браузері.

```
app/
├── page.tsx                    # Головна сторінка

│   ├── page.tsx               # Список калькуляторів
│   └── fop-tax/page.tsx       # Калькулятор податків ФОП
```

## 💰 Монетизація (для впровадження)

1. **Банківські партнерки** (300-1000 грн/клієнт)
   - Monobank, Приват24, ПУМБ

2. **Google AdSense**
   - Контекстна реклама в блозі
   - CPM: $1.5-$3.5 для України

3. **Партнерки бухсервісів**
   - Taxer, BookKeeper
   - Відсоток від підписок
