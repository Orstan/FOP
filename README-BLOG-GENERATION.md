# 🤖 Автоматична генерація блог-статей

Система автоматичної генерації SEO-оптимізованих статей для блогу ФОП Помічник.

## 📋 Що це робить?

- **Автоматично генерує** 2 нові блог-статті на тиждень (понеділок та четвер)
- **SEO-оптимізовані** статті з ключовими словами
- **Структуровані** як існуючі статті на сайті
- **Автоматично оновлює** список блогів та sitemap
- **Деплоїться** на Vercel після кожної генерації

## 🚀 Налаштування

### 1. Додайте OpenAI API ключ в GitHub Secrets

1. Перейдіть в репозиторій GitHub
2. Settings → Secrets and variables → Actions
3. Натисніть "New repository secret"
4. Назва: `OPENAI_API_KEY`
5. Значення: ваш OpenAI API ключ
6. Збережіть

### 2. Перевірте, що GitHub Actions увімкнено

1. Settings → Actions → General
2. Переконайтесь, що "Allow all actions and reusable workflows" увімкнено
3. Збережіть

## 📅 Розклад генерації

Статті генеруються автоматично:
- **Понеділок** о 12:00 (Київ)
- **Четвер** о 12:00 (Київ)

Це дає **2 нові статті на тиждень** = **~100 статей на рік**

## 🛠️ Ручний запуск

Якщо потрібно згенерувати статтю вручну:

1. Перейдіть в GitHub → Actions
2. Виберіть "Generate Blog Posts"
3. Натисніть "Run workflow"
4. Підтвердіть запуск

## 🔧 Налаштування тем

Щоб додати нові теми для генерації, відредагуйте файл:
`scripts/generate-blog-post.ts`

Знайдіть масив `blogTopics` та додайте нові теми:

```typescript
{
  title: "Назва статті",
  keywords: ["ключове слово 1", "ключове слово 2"],
  category: "Категорія"
}
```

## 📊 Моніторинг

Перевірити статус генерації:
1. GitHub → Actions
2. Перегляньте останні запуски "Generate Blog Posts"
3. Перевірте логи для деталей

## ⚠️ Важливо

- **API ключ** має бути дійсним OpenAI API ключем
- **Баланс** на OpenAI акаунті має бути достатнім
- **GitHub Actions** мають бути увімкнені
- Кожна генерація коштує ~$0.10-0.20 (залежить від моделі)

## 🎨 Кастомізація

### Змінити розклад

Відредагуйте `.github/workflows/generate-blog-posts.yml`:

```yaml
schedule:
  - cron: '0 10 * * 1,4'  # Понеділок та четвер о 10:00 UTC
```

### Змінити модель AI

У файлі `scripts/generate-blog-post.ts` змініть:

```typescript
model: "gpt-4-turbo-preview"  // або "gpt-3.5-turbo" для економії
```

## 🐛 Troubleshooting

**Проблема**: Генерація не запускається
- Перевірте GitHub Actions увімкнено
- Перевірте OPENAI_API_KEY в Secrets

**Проблема**: Помилка API
- Перевірте баланс на OpenAI
- Перевірте валідність ключа

**Проблема**: Статті не публікуються
- Перевірте логи GitHub Actions
- Перевірте права доступу бота

## 📞 Підтримка

При виникненні проблем:
1. Перевірте логи GitHub Actions
2. Перевірте налаштування API ключа
3. Перевірте баланс OpenAI акаунту
